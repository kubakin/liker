# Liker — лайки на последний пост ВКонтакте

Монорепозиторий: бэкенд NestJS + админка React. Ставит лайк на **последний пост на стене** указанным пользователям ВК (или участникам группы).

## Возможности

- **Несколько API-ключей**: на вход можно дать несколько access token; при лимитах/блокировке используется следующий ключ.
- **Лимиты и капча**: задержка между лайками (~3.5 с), при ошибке «слишком много запросов» или флуд-контроле ключ временно отключается и берётся следующий.
- **Капча**: при появлении капчи она показывается в админке; после ввода кода лайк отправляется с тем же ключом.

## Запуск

```bash
# Установка зависимостей (из корня монорепо)
npm install

# Бэкенд (порт 3001)
npm run api

# Админка (порт 3000, проксирует /api на бэкенд)
npm run admin
```

Откройте http://localhost:3000 — админка.

## Переменные окружения (бэкенд)

Переменные читаются из файла `apps/api/.env` (или корневого `.env`). Используется `@nestjs/config`.

- `PORT` — порт API (по умолчанию 3002).
- `DATABASE_URL` — строка подключения PostgreSQL (например `postgresql://user:password@localhost:5432/liker`). Пароль со спецсимволами можно задать отдельно в `DATABASE_PASSWORD`.
- `NODE_ENV` — в production отключите автоматическую синхронизацию схемы TypeORM (`synchronize: false` в коде при необходимости).
- `TYPEORM_LOGGING` — при значении `true` в консоль выводятся SQL-запросы.
- **OAuth ВК** (для кнопки «Получить токен ВКонтакте» в админке): `VK_APP_ID`, `VK_APP_SECRET`, `VK_REDIRECT_URI` (например `http://localhost:3002/api/auth/vk/callback`), `VK_FRONTEND_REDIRECT_URI` (URL админки, например `http://localhost:3000`). Приложение создаётся на [dev.vk.com](https://dev.vk.com/apps?act=manage), в настройках указывается тот же Redirect URI.
- **Авто-капча** (опционально): `CAPTCHA_SOLVER_API_KEY` — API-ключ [2Captcha](https://2captcha.com). Если задан, капчи при лайках решаются автоматически через этот сервис (платно).

## Как пользоваться

1. **Ключи** — добавьте токены вручную, нажмите **«Получить токен ВКонтакте (OAuth)»** (редирект на ВК) или **«Войти через VK ID»** ([VK ID SDK](https://id.vk.com/about/business/go/docs/ru/vkid/latest/vk-id/connection/start-integration/web/install)) — авторизация в окне без смены страницы. Для OAuth нужны `VK_APP_ID`, `VK_APP_SECRET`, `VK_REDIRECT_URI`; для VK ID — приложение в [кабинете VK ID](https://id.vk.com/about/business/) и `VK_ID_APP_ID` (или `VK_APP_ID`), в настройках приложения укажите Redirect URL: `https://ваш-админка/auth/vkid-callback`.
2. **Цели** — укажите список ID пользователей (по одному на строку или через запятую) **или** одну группу (ID или short name). Участники группы подтягиваются при старте задачи (до 10 000, пачками по 1000).
3. **Задача** — нажмите «Старт». Для каждого пользователя запрашивается последний пост на стене и ставится лайк. Логи и счётчики обновляются в реальном времени.
4. **Капча** — если ВК вернула капчу, она появится во вкладке «Капча»; введите текст и нажмите «Отправить». Если задан `CAPTCHA_SOLVER_API_KEY` (2Captcha), капча решается автоматически в фоне.

## Стек

- **API**: NestJS, Node 18+, TypeORM, PostgreSQL
- **Admin**: React 18, Vite, Tailwind CSS
- **VK API**: `wall.get`, `likes.add`, `groups.getMembers` (v5.131)

## База данных

Перед запуском API создайте базу PostgreSQL и укажите `DATABASE_URL`. При первом запуске TypeORM создаст таблицы (`synchronize: true` в режиме разработки): `api_key`, `targets_config`, `pending_captcha`, `job_state`.

## Ограничения

- Группа: загружается до 10 000 участников (пачками по 1000).
- Задержка между лайками фиксирована (~3.5 с), чтобы снизить риск лимитов и капчи.
